# 天数32G：以原serve命令选择4096框架默认预算

原CLI显式预算4096的短测已独立+3.09%，质量还在评测。本候选将选择落到 EngineArgs 原生默认配置赋值边界，保留原serve argv，不能借显式CLI版本正确率证明本候选质量。

仅iluvatar、指定MiniCPM路径/42层2048隐藏/16Q2KV头、BF16、单卡、无投机/LoRA/多模态、131072长度、chunked开启、balanced模式及默认/256seq受支持。只有未显式传预算时设4096，显式2048/8192保留，其他模式继续原方法；不读取或修改RNG。仍通过原生配置方法创建其余设置，不改模型、算子或采样算法。

CPU执行实际安装arg_utils原生赋默认值方法AST，12项guard、原始异常与预算回滚通过，选中后的EngineArgs完整状态与显式CLI4096完全相同。GPU服务还需证明原argv、实际预算4096/warm83和相同算子/缓存行为，再做新鲜质量/正式4K；未采用，当前正式4997.05不变。硬件profile未采集。
