# Top-P 插值搜索 V2

V1的普通输入候选在Triton编译时因p_pivot从FP32被推为FP64而拒绝；V1原始结果保留，控制GEO正常，不能当作插值性能负例。

此独立版本只把新增插值log下限从1e-38改成正常FP32范围内的1e-30，避免隐式FP64推导。log下限仅用于选择下一次探测点；原概率计算、重复值规则、32次迭代上限、1e-12终止条件、CPU严格质量门槛1e-6保持。TopK原生AST不变。模块名独立，旧源不修改。

仍比较10种输入、原始/改变输入后的同一Graph、7次轮转计时，各次10重放。当前最好控制为fixed32_geo与fixed16_geo；原生8K仅留历史对照。这里未测采样RNG、模型服务或Math-500，不根据CPU迭代数推断GPU收益。
