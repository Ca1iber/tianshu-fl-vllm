# GateUp BF16路由与行stride定位

首版13尺寸探测在M565非连续A时被数值断言截停，没有将其当作成功结果。独立布局诊断保留原容差atol.02+rtol.01，逐方法记录完整GPU违规元素，并保存实际违规位置经CPU点积独立确认；输入位、保护区、RNG不变。六个case共三阶段，36组选择/违规位置CPU检查通过。

连续M565、1537、2048、4096：两条路径均完整通过。非连续M565和1537：两条路径都至少有一阶段超容差，不静默忽略，不对失败case做性能比较。尚未接入服务。实际模型所有新路由必须明确处理连续性；本实验不是当前5375.50正式版出错的证据。

只在两条路径三阶段均正确后，九组交替20次Graph回放：M565 mm.540327ms→linear.435886ms（+23.96%）；M1537 1.246206→1.061621（+17.39%）；M2048 1.415687→1.171881（+20.80%）；M4096 2.849136→2.365859（+20.43%）。这只是组件吞吐比值，不是模型总吞吐收益。后续实际服务需新质量和对照。
