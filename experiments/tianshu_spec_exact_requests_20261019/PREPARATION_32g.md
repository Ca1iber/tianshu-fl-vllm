# 保持请求数的混合投机 CUDA Graph 候选

上一版请求数补齐在真实模型中未通过与未补齐 eager 的对照，现有证据尚不能确定算子错误。这个独立候选不补齐请求数：真实 N=16..64，每个 N 预捕获 token 以 8 向上补齐的 mixed Q1/Q2 图；248 个拥有者键，padding token 上限仍为 12.5%，超过合法 2N 容量或其他不支持情况均保留原执行路径。原 uniform 图键、prefill、采样与拒绝采样不变。

CPU 检查继续执行已固定的实际 Dispatcher 与 BatchDescriptor 源码，覆盖 248 种 dummy 元数据和全部 2144 个 Q1/Q2 分布。GPU 仍比较真实完整 hidden/logits 与同补齐及完全未补齐 eager，阈值 .02/.01 不变，核验 42 层 KV 恢复及 RNG；八样本分配改为峰值 N64 三个、57..63 非整桶尾部三个、16..56 尾部两个，与新的运行范围对应。

数值诊断使用原编译配置，不能以关闭编译的逐层观察版本替代。通过后另行设计 4K/1K 的服务对照，之后才做新的 Math-500 和正式评测。此候选目前没有性能或准确率结论。
