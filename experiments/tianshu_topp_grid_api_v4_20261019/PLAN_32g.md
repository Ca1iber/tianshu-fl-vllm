# Top-P grid API V4：逐请求独立回归门槛

GPU kernel、route、hooks与V3逐字相同。V2/V3失败原件保留。V3使用全矩阵“exact OR strict”会把一个请求的现用边界误差与另一请求的合法改变绑定，错误否决独立请求。

V4使用每行“保留值不变 AND（与现用该行逐位一致 OR 原严格CPU条件）”。CPU概率容差1e-6、严格logit顺序条件原样保留，不接受发生改变且严格条件失败的行。每行记录逐位、严格和相对门槛；旧全矩阵诊断也继续记录。CPU十个真假组合包含两行独立性反例。所有156mask、RNG21、lifecycle6、fallback8和260event不减。

完整原件下载/核验才生成GPU_GATE；服务原命令4K/1K C64 N64各3轮。不得声称每个输入严格CPU通过，不借用旧Math，不自动采用。若某一行发生变化且严格失败，保留真实失败并拒绝该候选。
