# 整数PV完整attention组件对照

复用已通过GPU全字数值验证的整数PV原语，新的试验目录不修改任何正在运行的8192正式4K源码。

比较K8V16、原生K8VI8Heads、PV32和PV64。后两者保持真实8448-byte页布局、原生QK/softmax和reducer，仅启用已经冻结的PV整数路径，并分别使用T32/T64、2warps；所以速度属于整套组件配置，不能独立归因于整数指令。现有对照为T16、1warp。

测试B1/33、B8/257、B40/4096、B64/4096、B64/5120。每种配置三阶段改变Q、K、V、scale、slot及长度，真实writer在每次图重放和计时内；检查全物理缓存、输入/RNG、输出及scratch保护区，全输出GPU参考和选定向量CPU FP64参考。七组轮换计时，每组二十次重放。

CPU gate仅说明来源和试验结构通过。GPU结果、性能和模型精度未产生前不声称收益；没有接入完整engine allocator，没有新Math，也未采用。原始张量只留容器，GitHub保留代码、报告和关键结果。
