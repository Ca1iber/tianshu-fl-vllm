# 已采用A8量化器的等价快速公式：CPU准备

当前GateUp/LM64已采用A8/W8。本方向优化已有激活量化器，避免新增权重副本/改变模型。原公式为scale=RN(max(abs(A),1e-8)/127)，q=RNE(RN(A/scale))。单纯把逐元素除法改乘倒数，可能在半整数临界值上改变q，先不假定等价。

候选对有限BF16输入使用RN(1/scale)乘法，并显式修正abs(A)==peak/2：一种用一次标量RN除法得到临界q；另一种用fma(-63.5,scale,peak/2)与-scale*2^-19比较，确定原FP32除法的RNE阈值。peak<1e-8或非有限时保留旧逐元素除法分支。scale公式保持。

覆盖：枚举所有>=1e-8的正有限BF16 peak；每个peak枚举0..9个指数差、128个mantissa、两个符号，排除abs(A)>peak；更小值满足127*(255/128)*2^-9<0.5，必须量化0。所有clamp区有限BF16另外覆盖。先CPU筛选，再实际GPU逐项与原量化器/独立CPU比较；CPU模拟不代替GPU FMA证据。

只有q和scale位级一致且实际形状有收益才考虑改已采用路径。新源/计划固定后验证，原源不改，profile/微测不能替代正式benchmark/Math。每日北京时间06:00–24:00，本日23:58硬截止。raw只在容器，源码报告关键结果推GitHub。
