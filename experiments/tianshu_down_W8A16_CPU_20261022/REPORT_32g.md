# Down仅量化权重、保留BF16激活：CPU误差分析

42层真实 Down 权重、504份旧合成工件全部检查通过。原逐输出 W8 打包保持一致，去掉激活 A8 量化、保留原 BF16 H，理想 W8A16 的相关验证相对 L2 误差为 **1.2534%**，普通 W8A8 为 **3.4638%**，相对减少约63.81%。这说明在本组工件中保留激活精度值得继续检查，不是 GPU 性能或 Math-500 结论。

| 方案 | phase0 相对L2 | phase1/2相关验证相对L2 |
| --- | ---: | ---: |
| 原W8A8 | 3.5616% | 3.4638% |
| 理想W8A16 | 1.2611% | 1.2534% |

INT8权重码[-127,127]可精确表示为BF16，未来可尝试在融合GEMM寄存器中转换权重码，做BF16输入/权重码点积，再乘每个输出的WS并只舍入一次BF16；不需要激活量化kernel，也不需要完整BF16解包权重缓冲区。但其算力、格式转换、访存开销必须实际GPU测试。

本CPU候选采用FP64点积后舍入FP32再乘WS，近似理想FP32累加，不是实际GPU的逐步FP32归约，不声称未来GPU逐位一致。旧phase1/2来自旧合成种子，是相关工件，非独立随机验证。新GPU实验需独立输入、数值误差界、组件性能验证，之后还需新鲜完整105条C8/C64质量。

全部504份工件、原权重/缩放的哈希通过检查；普通W8A8激活码、缩放、完整K的整数点积和最终BF16输出均独立重算并与原GPU工件完全相同。模型文件SHA256前后相同，未导入Torch、Triton、vLLM、FlagGems，未使用GPU，未修改模型文件或结构。此分析在正式计时评测结束后才运行，没有占用计时测试资源。当前尚无W8A16 GPU实现或采用版本。
