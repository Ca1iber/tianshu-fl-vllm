# 按输出行的软件8位权重：组件负收益，不采用

把真实BF16权重派生为每输出行一个指数起点的uint8编码，三位fraction和符号位；不是原生硬件FP8，不修改checkpoint。CPU720896个位模式/起点和2816码值契约通过；GPU全码值两相位同Graph逐位通过。

真实checkpoint第0层qkv/o/gateup/down、M64合成激活、每类8配置，共**32/32配置编译并完成计时**。每配置3组原生BF16/自写BF16/软件W8、同Graph三相位改变激活、权重符号和指数起点，**288项完整GPU FP32参考、73728个独立CPU标量**全部通过，输出/partial哨兵及RNG通过。W8参考使用独立CPU解码后的权重，不能把通过此参考当作原模型数值或Math质量通过。

| 投影 | 最快W8配置对应原生BF16 ms | W8 ms | 组件吞吐变化 |
|---|---:|---:|---:|
| QKV | 0.032270 | 0.049795 | -35.19% |
| O | 0.022891 | 0.037402 | -38.80% |
| GateUp | 0.095665 | 0.199018 | -51.93% |
| Down | 0.059155 | 0.092959 | -36.36% |

7轮×20同Graph重放、AB/BA顺序，计入split reduction，不计权重打包/分配。每种形状取W8时延最小的配置，原生对照取同组测量，仍明显负收益。权重约减半、真实权重无饱和，但无法补偿此实现的解码/内核成本；没有接服务或运行Math，不采用，也不影响当前正式最佳。
