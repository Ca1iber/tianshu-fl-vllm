尚无模型吞吐、fresh Math 或正式分数；未采用。源版本 faf2e7d。

当前 CoreX 的 native FP64 阈值路径再次产生全零随机值，三组 FP64 接受结果与 CPU oracle 不同。继承的正 FP32 阈值修复通过48组（含无draft概率、零proposal、混合greedy、64批次），65536值均值0.500227、unique65279。标准接受比率和恢复核保留，不启用 synthetic。原失败证据与修复源均归档；不能使用退化路径的吞吐作为成绩。

首次 Q2 attention 测试在 raw native L1 分母的 FP32 数值对照处失败（max abs0.16817），原因是 SPEC 关闭 hybrid，而原有 L0修正原在hybrid dispatch中应用。失败原件保留。后续明确以正确的 L0二维原生路径为基准，复用现有 producer/reducer，在128 query resident scratch支持下将 guarded unified dispatch的 max_query条件1→2，用原3D分段计算验证Q1/Q2；attention/reducer整数位置和浮点运算核不改。B≥8使用8segments，B1使用16。其他形状保持L0前向，长prefill复用已验证BM256/T128/w16。
