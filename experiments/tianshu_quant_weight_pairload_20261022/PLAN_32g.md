# W4 成对读取独立对照

上一版 W4 内核对相邻 N 分别重复读取同一 packed 字节，再按 N 奇偶动态移位。本版将 BK×BN/2 字节各读取一次，固定移位得到 low/high nibble，再 tl.interleave 成 BK×BN。量化格式、BF16 重建、FP32 dot、scale、tiles 和原始 checkpoint 保持。

这是明确的内核加载/解包方式实验，不以权重压缩率推算吞吐。先在离线 CoreX 编译中检查，再在前版 GPU 结束且实际卡空闲后启动。完整尾部/三相位/真实权重/独立 CPU 审核和 7×20 Graph 计时沿用，实际时间不直接跨进程相除作正式收益。若仍远落后 BF16/W8A8，则不接模型或 MATH。

预约每天北京时间 06:00–次日 00:00；本日硬截止 23:58。每个组件作业 30 分钟硬上限。GPU 作业无重叠，raw 只在容器；代码、报告和关键数据放天数 GitHub。原 V1/V2 冻结源与失败记录保留，本版使用新源/新 raw 目录。
