# K8V16 物理页间隔：准备阶段

不改 K 编码、V BF16、attention 算术、tile/warp/segment 策略，仅在每个12KiB物理页后追加128/256/512/1024/4096字节空隙，测试地址分布与对齐是否影响实际读写耗时。此时只是可检验假设，没有硬件计数器证明其根因。

复用已通过的8场景、两次变输入的同一CUDA Graph、完整GPU FP32和CPU抽样参考、whole-storage writer检查、padding/segment/RNG保护。新增控制/候选attention输出逐位相等要求。所有布局保留同一逻辑数据及随机页表，9轮正反交错×20重放，包含原writer和单层attention。无引擎、模型或正式吞吐成绩；有明显组件收益后才考虑真实allocator的额外容量成本。

源码由已验证的V线性编码探针复制，只把候选模型集合改为六种物理页间隔；所有denominator均为None，V量化分支不执行。新目录修改不触碰原来冻结源。GPU必须等待当前服务及子进程退出、显卡空闲后串行执行。
