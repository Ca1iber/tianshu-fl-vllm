# M64真实权重GEMM：49配置搜索

四个实际第0层投影（QKV/O/gateup/down），每种49组BM/BN/BK/split/warp配置，共196组。输入、权重和输出BF16，累加FP32；使用已有kernel，不改checkpoint、vLLM或FlagGems安装源。B64仅组件筛选，尚无新服务、Math或正式benchmark结果。

每组两个原位改变激活/权重的同一Graph相位，同时对完整GPU FP32结果及CPU8×32标量参考验证，atol=.02/rtol=.01。所有196组编译通过，784次完整GPU数值检查、200704个CPU标量独立重核通过；输出和split临时张量尾部保留，RNG不变。7轮AB/BA交错，每轮20重放，计入split reduction，不计分配。
