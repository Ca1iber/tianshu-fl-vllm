# PV逐元素除法与按行倒数复用

前版PV32完整组件数值通过但明显负优化。本实验保持相同真实页布局、T32/2warp、writer/QK/softmax/reducer；严格PV32仍使用逐元素div_rn，PVR32只改为每行先求一次div_rn(1,scale)，再乘weighted并nearbyint。权重/scale生成、正负V及在线softmax不改。K8V16和原生V8作为两个额外对照。

浮点运算顺序变化可能使少量P量化整数相差1，因此不把旧原语逐字证据借给新路径；独立CPU FP32操作检查只证明意图与边界，仍需相同五组case、三阶段的GPU全输出/保护区和CPU FP64数值复核。误差门槛保持atol0.02+rtol0.01。

先测组件成本，GPU作业排在6144服务对照成功完成后且确认实际卡空闲。没有性能数据前不声称加速；只有接近或超过现用K8V16才考虑整模型与新Math。全部raw留天数容器，GitHub只存代码、报告和关键结果。
