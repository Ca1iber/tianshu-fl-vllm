# 天数 GateUp 与 SiLU 融合候选

该模型的 config 实际声明 `LlamaForCausalLM`，MLP 是 GateUp、SiLU/乘法、Down 三步。候选在一个 GEMM CTA 中同时计算配对的 gate/up 列，不重排权重；保留 GateUp 的 BF16 中间舍入，按照已缓存的 Inductor 内核在 FP32 做 SiLU 和乘法，最终写回 BF16。未修改安装源码，尚未运行 GPU 实验。

数值实验计划覆盖 8 个场景、7 个配置：M8/16/32/64、模型尺度和单位尺度压力、M17以及非整齐中间维度130。比较原生NT GEMM加单个编译激活内核、FP32与选定CPU参考；保留实际缓存的激活源码、输出尾部检查和交替 CUDA Graph 事件计时。

误差检查明确采用 atol0.1/rtol0.02（包含单位尺度投影和乘积的放大），数值实验不能代替对应的完整105题质量。当前只是待筛选原型，不计入正式最佳；实际服务、质量和完整4K均尚未运行。串行等待先前实验清理GPU，截止读取用户延长后的预约。
