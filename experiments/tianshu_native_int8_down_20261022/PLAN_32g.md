# Native INT8 Down — frozen component experiment

Current recommended r1 keeps Down BF16. Test native W8A8 Down for M64/128/512/4096, real original layer0 Down weight2048x6144. Two possible physical layouts NT/NN, one packed layout per eventual integration; two epilogue block sizes512/1024, warps4. Same existing A8 quantizer and generic LM64 dequant JIT, no new numeric JIT. This adds approximation to a currently BF16 operation; no claim of model quality from component numerical tests.

Generate Down input with real original layer0 GateUp weights, existing row-A8/output-W8 quantization, native INT32 and the frozen exact BF16-projection/SiLU epilogue. These GateUp values match qualified r1 component mathematics (including M64 equivalence tested previously), but generation time is excluded and no whole-MLP performance claim is made. Original model is never executed. Candidate quantizes this BF16 hidden tensor along K6144, not the pre-activation input. Baseline is original BF16 torch.mm using the same hidden values and real BF16 Down weight.

Three phases change original GateUp activation sign/scale and Down weight sign/scale. Candidate full INT32 and BF16 output must exactly match independent original Triton dense W8A8 diagnostic GEMM; all four candidates must be bit identical. Poison output/integer before graph replay and require exact eager equality. Full original inputs/weights/scale/RNG and sentinels unchanged. Record approximation error against BF16 baseline (L2 normalized RMS and max absolute); it is an approximation measurement, not a new accuracy score. GateUp M512/4096 epilogue full binary must match qualified hashes.

CPU independently re-quantizes real Down weight, each complete saved hidden fixture and A8 scales; verifies selected INT64 products and exact dequant BF16, plus selected BF16 baseline against FP64 reference .02+.01*abs(reference). All full hidden fixtures and raw logs stay container-only. Frozen plans/source including original r1 checked before/after, original checkpoint SHA unchanged. New isolated cache; no mutation of recommended cache/launcher.

Seven rotating-order rounds x10 calls for each complete arm (A8+int_mm+dequant), both graph and eager.
