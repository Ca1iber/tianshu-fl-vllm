# 真实服务冷启动对照结果

`verify_cold.py` 在三组完整运行后独立检查全部 329 项源文件与 snapshot、59 项实际环境、43 组原始 BF16/INT8/scale 全量哈希、恢复后的 CPU 线程、同一已采用的 SQL 策略、真实 KV 容量、576 个成功请求、调度释放与无现场调优，然后生成关键 JSON 与 CSV。

三组分别为 native 默认 CPU 线程、cpu4 加载期间 4 线程 CPU 打包、gpu4 加载期间 4 线程 GPU 打包。每组冷启动一次、三轮 4K/1K C64 N64，首轮不计小规模均值。单次冷启动不代表重复启动分布，不计作新正式成绩，也不声称新 Math。正式最好仍以已推送 release tag 为准。
