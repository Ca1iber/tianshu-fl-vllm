# 单dot首组逐位失败的完整阶段诊断

原32组组件在M8/contiguous前4组two_dot通过后，首个single_dot(bm32/bn64/bk128/w2/s1)phase0输出逐位不等，原失败与冻结代码保留。此诊断只复现同一个确定输入，不重跑性能/Math，不修改原kernel。保存native完整INT32/BF16投影/输出、candidate实际Graph版本完整输出，以及DIAGNOSTICS=True特化的完整INT32/投影/输出；分别记录两个binary与寄存器，核实际版本是否和原失败binary相同。诊断特化不能自动代表实际计时版。

全部输出先落盘再评判。独立CPU从完整packed W签名核真实模型权重，完整A量化和98304个INT64点积及BF16投影，报告数值差异数、绝对误差、原CPU容差失败数；不把差异自动当通过。600秒上限、23:58硬停，边界/RNG/输入/权重保护，debug结束GPU空闲。若只有激活微差，后续新版本需要事先合理误差界限及新模型Math，原逐位gate仍失败；若整数或投影不对，先修正实现，不能用容差掩盖。
