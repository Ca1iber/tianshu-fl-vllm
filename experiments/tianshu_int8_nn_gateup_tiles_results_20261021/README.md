# GateUp NN 固定分块结果复核

此目录只做离线 CPU 复核，不修改正在运行探针目录或其冻结源码。读取最终 result.json、源快照 SHA、17 预声明候选与两种 M、所有七轮交替 / 40 replay 记录；独立从 checkpoint 选中原行重新量化、全部 A 量化、实际 GPU 整数输出 INT64、选中 BF16 验证。完整设备输出逐位对照由原始冻结 GPU 探针执行，离线复核不冒称全部输出 CPU 重算。编译失败保留并排除。

best_by_M 是探索性 17 选一，未来需要独立验证或模型服务测试，不当成模型 benchmark 收益。原始 PT/源码快照只容器。
