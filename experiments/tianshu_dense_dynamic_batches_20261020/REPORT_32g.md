# 动态批次整数GEMM：仅M32直接配置有收益

12个实际权重案例、48配置×3改变输入/权重的阶段，通过完整设备整数检查、量化输出检查、独立CPU全A与选中W重新量化/INT64点积共144组。全部输入/RNG/边界保持。7轮交替顺序×20热Graph，计时包括A量化+GEMM，W静态打包明确排除。不是模型/正式成绩，未自动采用。

M32 GateUp最优0.092491→0.059859ms（+54.52%速度），LM显式vendor linear基准0.937382→0.549464ms（+70.60%）。但M37/40/48/56/63，GateUp最优约0.133ms，比BF16 mm约0.094～0.096ms慢；LM最优约1.325～1.338ms，比显式vendor linear约1.049～1.142ms慢。不能将M64配置直接推广到所有动态批次。

M64合格原语GateUp已测约0.0687ms，这与masked中间批次的差异提示可单独验证整tile补齐，但不是已经测出的补齐收益。LM基准显式flag_gems.linear不等同现有服务完整F.linear分发路径，组件差值不能直接当成服务LM收益。

完整原始.pt/日志留容器。Git只保留GPU_GATE/ROUNDS、报告和验证代码。
