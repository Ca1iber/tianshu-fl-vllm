# Uniform-int8 K / BF16 V：新的数值格式候选

仅CPU准备，尚未GPU/服务/新Math或正式成绩；当前正式best4997.05保持原软件E4M3 K/BF16 V。
新方案保留12KiB物理页、BF16 V、模型/Q/输出、线程配置及64位偏移，
将K改成对称定步长signed int8，step=1/4，编码范围[-127,127]对应[-31.75,31.75]。
采用nearest-even舍入后饱和；NaN映射0，正负Inf饱和，-0归零，原始carrier仍UInt8。
它改变KV数值，任何算子FP32参考通过都不能代替完整模型的新Math>95%质量验证。

假设是替换K解码的位运算为signed转换和一次常数乘法，降低读取侧开销；
编码侧可能更贵。测试包括实际writer+decode，因此不会只测读取收益。
保留相同逻辑Q/K/V和页表，分别以各自量化结果构造FP32及CPU参考，
检查变数据同Graph、完整物理存储、padding/scratch/输入和RNG。不同格式不要求输出逐位相同。
控制沿用已验证K8V16，候选必须额外穷举65536个实际GPU编码及256个实际解码。
CPU侧以独立浮点/整数位两种算法穷举交叉验证舍入/饱和/非有限值规则。
