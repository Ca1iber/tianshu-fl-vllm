# 天数32g：M4096 Prefill GEMM独立探索

4096预算的服务短测已独立确认提升3.34%，真实模型可能出现M4096投影。原M2048候选服务只有+0.83%，不能把该尺寸的结论直接迁移。本实验仅改变独立合成探针的输入行数为4096，保持hidden2048、QKV2560、gateup12288、down输入6144的实际模型维度。

复用已保存的独立BF16 NT GEMM诊断内核，不改安装源码和当前活动质量/正式服务。10组tile/group参数×4投影=40组，与原FlagGems mm对照；剔除旧实验中四投影均确定超共享内存上限的2组配置。完整GPU FP32参考、CPU样本、改变Graph输入重放以及交替7组设备event计时保留。失败配置也保存。

当前仅CPU准备，尚未执行GPU，不代表服务吞吐或质量收益。后续要在GPU空闲、现有Math及正式4K都结束后串行运行；明显有利才接真实服务小规模对照。未采硬件profile。
