# 当前K8V16版本的历史代码输入恢复

已验证的4096预算启动器冻结205份源，其中22个路径位于历史benchmark-results目录。它们只有3份不同Python内容，总计104171字节；本目录把这3份代码按SHA256去重保存，附原路径清单。没有模型、缓存、张量或完整benchmark原始数据。

在天数容器内、仓库与依赖准备完成后运行：

```bash
bash experiments/tianshu_k8v16_restore_inputs_20261020/restore.sh
```

脚本使用mkdir、cp和sha256sum恢复缺失文件；已存在但哈希不同的文件会报错，不会覆盖。使用普通文件保留原始绝对路径语义，不创建指向仓库的符号链接。随后仍由原启动器检查全部205份源。

验证范围：在容器内全新隔离目录恢复22个路径并逐一检查哈希，再次运行验证已有文件分支；对正式历史路径只检查现存文件。未修改正在评测的任何输入，也未声称全新容器的依赖安装和整套服务复现已经通过。
